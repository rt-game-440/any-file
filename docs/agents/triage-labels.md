# 分诊标签（Triage Labels）

工程技能内部使用 5 个标准分诊角色。本文件将这 5 个角色映射到本仓库 Issue 追踪器中实际使用的标签名称。

| mattpocock/skills 中的角色 | 本仓库实际标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估此 Issue |
| `needs-info` | `needs-info` | 等待提交者补充更多信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可交由后台 Agent 自动实现 |
| `ready-for-human` | `ready-for-human` | 需要人工介入实现 |
| `wontfix` | `wontfix` | 不予处理 |

当技能提到某个分诊角色（例如“打上 AFK-ready 分诊标签”）时，使用上表中对应的“本仓库实际标签”名称。

如需调整为其他命名习惯，直接编辑“本仓库实际标签”列即可。
